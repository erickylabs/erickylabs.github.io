AWS Drupal Deployment

I deployed Drupal on AWS using EC2 and RDS MariaDB, connected my domain, and set up HTTPS.

What I did

  • Deployed the Drupal application on Amazon EC2.
  • Connected Drupal to an Amazon RDS MariaDB database.
  • Pointed my domain to the website and configured HTTPS.
  • Checked the website and Drupal admin page.

This was a CIT 270 course lab. A running instance was one part of the work; I also needed the application, database connection, domain, and HTTPS working together.

The CIT 270 lab earned an A.
